Harness

Скачать VSIX

Агент для работы с кодом в VS Code. Подключай GLM или Codex, запускай инструменты и продолжай длинные задачи в чате.

Как установить

Ручная установка
  1. Скачай Harness.vsix.
  2. В VS Code открой палитру команд (⌘⇧P или Ctrl+Shift+P).
  3. Выбери Extensions: Install from VSIX… и укажи скачанный файл.

На macOS, если команда code отсутствует, выбери Shell Command: Install 'code' command in PATH в палитре VS Code и открой терминал заново.
